# שולחן מתקפל לסולם השוודי — Swedish ladder folding table (3D concept)

קונספט תלת־ממדי אינטראקטיבי לשולחן מתקפל שמתלבש על שלבי הסולם השוודי של **Ezoon**
(סולם 7 שלבים עם מתקן מתח/מקבילים, נרכש ב־KSP מק״ט 380571).

**אתר חי / Live:** https://horizonbuilds.github.io/swedish-ladder-table/

**דפלוימנט:** GitHub Pages (branch `main`, root) — סטטי, בלי build step.

## מה יש כאן
- מודל Three.js אינטראקטיבי: סיבוב, זום, מעבר פתוח/מקופל באנימציה.
- סליידרים פרמטריים: אורך/עומק שולחן, שלב תלייה, גובה התקנה של הסולם.
- הפרדה ויזואלית בין מידות **מאומתות מהיצרן** (ירוק) לבין **הנחות קונספט** (כתום מקווקו).

## מידות מאומתות (KSP / ezoonboard.com, 15.11.2026)
- רוחב סולם 62 ס״מ · גובה 118 ס״מ · 7 שלבים · עומק מתקן מתח ≈50 ס״מ מהקיר
- עומס מירבי 120 ק״ג (דירוג אימון אנכי של היצרן — לא תקפות לשולחן תלוי)
- קיבוע לקיר בטון/בלוקים בלבד, 8 דיבלים 10 מ״מ בעומק 80–90 מ״מ

## הנחות שדורשות מדידה לפני ייצור
קוטר שלב (הונח 30 מ״מ) · ריווח שלבים (נגזר ≈16.9 ס״מ) · מרחק שלב מהקיר (≈7.5 ס״מ) ·
פרופיל מוטות צד · גובה תחתית הסולם מהרצפה (קובע את גובה השולחן).

## ⚠️ בטיחות
קונספט מכני להמחשה בלבד — לא שרטוט ביצוע, לא דירוג עומס, לא אישור בטיחות.
אין לייצר או להעמיס לפני מדידת המידות החסרות ובדיקת יציבות בפועל.

## טכנית
`index.html` + `main.js` + `style.css` בלבד. Three.js 0.160 מ־CDN (jsdelivr) דרך import map.
אין תלויות build. לשינוי: עורכים, עושים push, ו־Pages מתעדכן.
